# Жемчужная волна

Адаптивный свадебный сайт-приглашение в перламутровой стилистике.

- Данные загружаются по ID из Xano.
- Поддерживаются русский, кыргызский и казахский языки.
- RSVP сохраняется через PATCH API.
- Карты открываются через прямые ссылки или поиск по адресу.
- `/preview` — облегчённый первый экран без API и JavaScript.
